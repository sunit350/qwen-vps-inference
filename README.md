# qwen-vps-inference
# Qwen VPS Inference Lab

A hands-on project to deploy, benchmark, and
optimize open-weight Qwen language models
on a CPU-only VPS.

## Infrastructure

- CPU: 4 vCPU (AMD EPYC)
- RAM: 15 GiB
- Storage: 193 GB
- Deployment: Docker
- LLM Runtime: Ollama

## Learning Objectives

1. Deploy Qwen models locally
2. Understand inference parameters
3. Benchmark model performance
4. Monitor CPU and memory usage
5. Build an inference API
6. Integrate with Langflow
7. Prepare for commercial deployment
